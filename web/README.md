# Web

React + TypeScript (Vite). Talks to the backend at `VITE_API_URL` (default `http://localhost:8000`).

```
npm install
npm run dev      # http://localhost:5173
```

| Folder | What lives there |
|---|---|
| `src/api/` | backend client and shared types |
| `src/pages/` | screens: firms, record, memo, onboarding |
| `src/canvas/` | HTML/SVG painter of the memo's elements and editing |
| `src/components/` | shared UI pieces |
