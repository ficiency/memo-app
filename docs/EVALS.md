# Evals

Only what the brief asks (section 05, "How you know it works"):

> "It looked right when I opened it" is not a result. Build a suite of the edits real people make on the
> canvas, through the agent and in PowerPoint: drop an image, drag into a locked zone, duplicate a slide,
> type over a figure, paste a chart as a picture. Run it through repeated round trips with two people
> editing. Report, for each firm: edits that survive and conflicts surfaced rather than lost; how much of a
> canvas slide survives PowerPoint and back; overflow on a long-content set you write; AI edits that leave
> the memo invalid or its linked figures inconsistent; how closely a past memo can be rebuilt; and the time
> and cost of a render. When the third firm arrives, report how much took configuration and how much took
> code.

And from the challenge section: show **where your system breaks and how often**.

## 1. The suite

The five edits the brief names, made in each of the three editors, on each firm:

| Edit | Canvas | Agent | PowerPoint |
|---|---|---|---|
| Drop an image | ✓ | ✓ ("add this image") | ✓ (insert a picture) |
| Drag into a locked zone | ✓ | ✓ ("move this into the header") | ✓ (move a box onto a locked area) |
| Duplicate a slide | ✓ | ✓ | ✓ |
| Type over a figure | ✓ | ✓ ("change revenue to …") | ✓ |
| Paste a chart as a picture | ✓ | — | ✓ |

**Repeated round trips with two people editing:** one round = two people edit at once on the canvas → the
agent edits → export to PowerPoint → edits in PowerPoint → import. The rounds repeat (5 by default).
Two people are two scripted clients on the same memo; PowerPoint edits are scripted on the exported file.

## 2. What is reported, per firm

| # | Measure | How we count it |
|---|---|---|
| 1 | Edits that survive, and conflicts surfaced rather than lost | Edits present at the end ÷ edits made; every edit not applied is visible with its reason (refused or kept aside), none disappears |
| 2 | How much of a canvas slide survives PowerPoint and back | Elements that come back as the same element (same identity, type, position, content, style) ÷ elements exported, per element type |
| 3 | Overflow on a long-content set we write | Slides with more content than fits: how many continue or split by the firm's rules, how many are reported as not fitting, how many are cut silently |
| 4 | AI edits that leave the memo invalid or its linked figures inconsistent | Agent edits applied after which the memo breaks a firm rule or a figure no longer matches the record (or differs between text, table and chart) |
| 5 | How closely a past memo can be rebuilt | Rebuild each past memo's deal from the spec and the record; compare with the original: slides, elements, figures |
| 6 | Time and cost of a render | Seconds and model cost to produce the memo and its outputs |
| 7 | Third firm: configuration vs code | What Lumen took as configuration (spec produced by onboarding) and what took code (lines changed) |

**Where it breaks:** every failure is listed with the measure, edit, editor, firm, round, how often it
happened and its cause. Fixes are made when they are generic; when the next fix would only fit a demo firm,
the failure stays listed as such.

The report is generated by `evals/run.py` into `evals/reports/<date>.md`.
